Security shouldn't be a feature you add once you get big. It should be part of
how the product works from the start.

## Built-in organizations

Every workspace is an organization with roles, teams and scoped permissions.
Access is a first-class concept, not a setting buried in a menu.

## Granular file permissions

Files inherit permissions from their folder, and you can override at the
individual file — view, comment or edit. Sharing is explicit, never accidental.

## Enterprise when you need it

When you're ready, Enterprise adds SSO, SCIM provisioning, audit logging and
configurable retention. Same product, stronger controls.

Security is table stakes for the work our customers do. We treat it that way.
